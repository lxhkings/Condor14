# ads.txt Generator Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Generate and serve `public/ads.txt` so Google AdSense recognizes the authorized publisher and flips the site status from 未找到 (not found) to 已授权 (authorized).

**Architecture:** Add a `generate_ads_txt()` generator alongside the existing `generate_robots_txt()` in `site_builder/sitemap.py`, wire it into `build_site.py` next to the robots.txt write, and commit a static `public/ads.txt` so the file ships on the next deploy without waiting for a cron build.

**Tech Stack:** Python 3, pytest, existing static-site build (`build_site.py` + `site_builder/`).

### Task 3: Ship ads.txt immediately

**Files:**
- Create: `public/ads.txt`

Rationale: `public/` is committed and served directly by Vercel. Committing the file now deploys it without waiting for the next cron build.

**WARNING:** Do NOT run `build_site.py` locally to generate this file. It requires
`SITE_HOST=www.condor14.com` env var; without it, it defaults to `condor14.com` and
overwrites all HTML canonical URLs in `public/` — polluting the working tree.

- [ ] **Step 1: Write the file directly**

```python
from pathlib import Path
Path("public/ads.txt").write_text(
    "google.com, pub-6718270775160916, DIRECT, f08c47fec0942fa0\n"
)
```

Or via shell:

```bash
printf 'google.com, pub-6718270775160916, DIRECT, f08c47fec0942fa0\n' > public/ads.txt
```
